# Grab the Mic 🎤

A phone party game. Put something mic-shaped on the table (a deodorant, a toilet roll, a water bottle), reveal a word card, and race to grab the "mic" and sing a line from a song that contains the word.

**Play:** https://czadam.github.io/grab-the-mic/

- Cards in English, Hungarian, or both (one language facing each end of the table)
- Optional scorekeeping: +1 for the one player who sings it right, −1 for anyone who messes up
- 302 English–Hungarian word pairs in `words.js`
- Plain HTML/CSS/JS, no build step: open `index.html` to run it locally
